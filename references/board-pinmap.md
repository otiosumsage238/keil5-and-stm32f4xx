# 板子引脚地图（XYD 智慧生活 / 智能锁开发板，STM32F405VGT6）

## 外设分配

| 外设 | 引脚 | 有效电平 / 参数 | 备注 |
|---|---|---|---|
| LED1 / LED2 / LED3 | PD12 / PD13 / PD14 | **低电平点亮** | 推挽输出 |
| KEY1 | PA0 | **按下为高**（外部下拉） | 浮空输入 |
| KEY2 / KEY3 | PB0 / PB1 | 按下为低（外部上拉） | 浮空输入 |
| 蜂鸣器 BEEP | PD15 | 高电平响 | 与 LED 同在 GPIOD |
| 继电器 RELAY | PE0 | 高电平吸合 | |
| 舵机 | PA1 | 50Hz PWM，0.5~2.5ms 对应 0~180° | 可用 TIM2_CH2 或 TIM5_CH2 |
| 风扇 / 直流电机 | PC8 | PWM 调速（低边 MOSFET 驱动） | 可用 TIM3_CH3 或 TIM8_CH3 |
| 温湿度 SHT30 | PB6=SCL / PB7=SDA | 地址 0x44 | I2C1，板上已有 4.7K 上拉 |
| 红外测温 MLX90614 | PB6 / PB7 | 地址 0x5A（8 位写 0xB4） | **与 SHT30 共用 I2C1**，靠地址区分 |
| 调试串口 | PA9=TX / PA10=RX | 115200 8N1 | USART1 |
| 语音模块 HLK-V20 | PD8=TX / PD9=RX | 115200 8N1 | USART3 |
| LCD（ST7789VW，1.3" 240×240） | SCK=PB3 / MOSI=PB5 / CS=PB4 / **DC=PD3** / **BLK=PD4** | 4 线 SPI | 显存 240×320 → 需 25 行 Y 偏移 |
| 触摸屏 CST816S | SCL=PA8 / SDA=PC9 / RST=PD5 / INT=PD1 | 软件 I2C（I2C3 那组脚） | 与 I2C1 不是同一条总线 |
| 光敏 / 火焰 ADC | — | ADC 采集 | |
| WS2812 彩灯 | 单总线 | 需微秒级时序 | 参考工程有 `WS2812.c` |

## 注意点

- **文档与代码冲突时以驱动代码为准**：老师第 4 章文档写 `LCD_DC=PD2 / LCD_BLK=PA15`，
  但驱动代码和参考工程 `st7789.h` 都是 **DC=PD3 / BLK=PD4**（文档那两行是旧版残留）。
- HLK-V20 那几个 `GPIO_A25~A28` 在本板上**没有引出来**，语音控制只能走 UART（Pin16/15）。
  其中 A28 在标准开发板上是功放使能脚，别乱配成 GPIO 输出（会影响播报）。
- 板上 `J4` 有一组"串口选择"跳线（`U1T/U1R`、`CRX/CTX`、`U2R/U2T`）：
  烧录 HLK-V20 时要把 CH340 选到模块那一组（CRX/CTX ↔ 模块 B7/B6，注意交叉 + 共地）。
